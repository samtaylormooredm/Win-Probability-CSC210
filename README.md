# Win Probability Model for A-10 Basketball (CSC 210)

## Overview
This project develops a win probability model for predicting outcomes of college basketball games in the Atlantic 10 (A-10) conference, with a focus on Davidson College and its opponents.

Using historical and current-season data, the model computes pre-game win probabilities based on advanced basketball metrics. The system includes a full data pipeline, predictive model, and an interactive Python GUI for user-driven predictions.

## Features
- Data cleaning and preprocessing pipeline for multi-season game data
- Feature engineering using advanced basketball statistics
- Custom weighted scoring model for win probability prediction
- Accuracy evaluation (73.33% on 2024–2025 season)
- Interactive GUI built with Tkinter for real-time predictions

## Model Details
The model is inspired by Dean Oliver’s Four Factors of Basketball Success, using:

- Effective Field Goal Percentage (eFG%)
- Turnover Percentage (TOV%)
- Offensive Rebounding Percentage (ORB%)
- Free Throw Rate (FT%)

Weights were optimized using regression on historical data and extended with:
- Steal rate
- Block rate

Predictions are generated by:
1. Computing team-level averages from prior games
2. Calculating matchup-specific net advantages
3. Applying weighted scoring
4. Normalizing scores into probabilities

## How to Run
1. Clone the repository:
git clone https://github.com/samtaylormooredm/Win-Probability-CSC210.git
cd Win-Probability-CSC210

2. Install dependencies:
pip install pandas numpy

3. Run the predictor:
python scripts/a10_predictor.py

4. Use the GUI:
- Select two A-10 teams
- Click Predict Winner
- View predicted winner and win probability

## Results
- Model accuracy: 73.33% on the 2024–2025 season  
- Correct predictions: 110 out of 150 games  
- Demonstrates strong predictive power using only pre-game team statistics

## Limitations
- Uses only team-level data (no player-level stats)
- Does not account for injuries, momentum trends, or in-game dynamics
- Limited to A-10 conference and two seasons of data

## Future Improvements
- Incorporate player-level and injury data
- Add temporal weighting (recent games matter more)
- Expand to additional conferences and seasons
- Support live, in-game probability updates
